# Design System

Design tokens are defined in `src/styles/`.

Core token files:
- `colors.ts`
- `typography.ts`
- `spacing.ts`
- `shadows.ts`
- `radius.ts`
- `motion.ts`
- `gradients.ts`
- `glass.ts`
- `zIndex.ts`
- `tokens.ts`

Use tokens instead of hard-coded values. Components should be styled with utilities or design-system primitives.
