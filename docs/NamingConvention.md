# Naming Convention

Use consistent names for files and symbols.

- Feature folders: `camelCase` or `kebab-case` for directories
- Component files: `PascalCase.tsx`
- Hooks: `useFeatureName.ts`
- Utilities: `featureNameUtil.ts`
- Types: `featureName.types.ts`
- Constants: `featureName.constants.ts`
- Services: `featureName.service.ts`
