# Folder Structure

This repository uses a feature-first layered architecture.

```
src/
├── app/
├── features/
├── shared/
├── entities/
├── widgets/
├── services/
├── infrastructure/
├── lib/
├── config/
├── hooks/
├── store/
├── styles/
├── assets/
└── types/
```

Each `features/` folder is self-contained with its own components, hooks, services, and types.
