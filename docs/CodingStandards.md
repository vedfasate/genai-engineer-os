# Coding Standards

- ESLint + Prettier for formatting and linting
- Strict TypeScript with `noImplicitAny`, `strictNullChecks`, and type-safe patterns
- Feature-first architecture with self-contained modules
- No duplicated logic; centralize shared helpers
- Accessible UI with semantic HTML and keyboard support
- Lazy load pages and components where appropriate
- Error boundaries for client-side rendering failures
- Centralized constants and validation logic
- Reusable components over one-off markup
