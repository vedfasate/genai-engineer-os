# Folder Convention

Follow a feature-first architecture with clear separation between layers.

- `src/app/` - App Router pages and layouts
- `src/features/` - Self-contained business modules
- `src/domains/` - Domain models and business rules
- `src/shared/` - Reusable components and utilities
- `src/widgets/` - Larger UI compositions
- `src/services/` - API and business logic
- `src/infrastructure/` - Adapters for storage and auth
- `src/core/` - Application systems and platform services
- `src/styles/` - Design tokens and style primitives
- `src/types/` - Shared TypeScript types
